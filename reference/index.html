The three shortlisted apps: basic + advanced timers, stacking, your own timers and sets

  • Seconds (iOS + Android): quick Countdown and Stopwatch modes beside a Circuit Timer. The circuit editor has a name, number of sets and a list of your own exercises, each with a time pill and an "Add Exercise" row, plus cut / copy / paste. Saved timers live in folders. Run screen is full-screen color with an "up next" panel.
  • Intervals Pro (iOS): the "Add New Timer" screen sets the ladder from simple to advanced: HIIT Timer, Custom Interval Timer, Set Timer. A separate Workout Templates list gives optional starting points.
  • TimeIt (this app): Simple uses rounds for work/rest. Advanced uses rounds too — each round has its own phase stack and may differ from the others.
  • Allez (Android): a "Quick routine" screen (Get ready, Warm-up, Work, Rest, Sets, Recovery, Cycles, Cooldown) next to saved Routines built from blocks ("Add block" is marked PRO). Bottom tabs: Quick, Templates, Routines, History, Settings. Templates are a separate tab, so your own routines stay separate.
  • Not verified: whether you can delete the sample or template content, and how the create / edit / delete flows behave. That needs hands-on use. Store screenshots are curated marketing frames.
