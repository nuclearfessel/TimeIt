# Timed — complete branding and graphics

Start with **Instructions/GITHUB-IMPLEMENTATION.md**. This is a separate Timed
handoff, not a Shopped/EncodeIt recolor.

## Contents
- Brand/: transparent horizontal, stacked and wordmark SVG/PNG pairs; color,
  black, white and grayscale marks; separate optional tagline lockups in both themes.
- Graphics/: light/dark README banners, features, workflow, phase explainer,
  simple/advanced comparison, illustrated session overview, run controls,
  mobile platforms and 1200×630 social cards, each SVG + PNG.
- AppIcons/: iOS asset catalog, 1024px store master, Android adaptive PNG layers,
  monochrome resources, legacy densities and 512px Google Play icon.
- Store/: light/dark 1024×500 Google Play feature graphics, SVG + PNG.
- Fonts/ and Licenses/: the existing Hepta Slab and Plus Jakarta Sans faces,
  local WOFF copies and SIL Open Font License notices.
- Web/: theme tokens, scoped starter CSS, browser favicons and a protected
  logo for the existing colored GitHub Pages headers.
- Instructions/: branding rules, GitHub handoff, README usage, website direction,
  mobile icon integration and verification checklist.
- Previews/: separate single-theme contact sheets, brand overview and icon board.
- Sources/: portable generators and requirements for regenerating the artwork.
- asset-manifest.json: file sizes and SHA-256 hashes.

SVG lettering is outlined, with no external font dependencies. All SVGs are
genuine vector shapes and lettering, not embedded screenshots. PNGs are renders
of the same artwork. Standalone logos are transparent; documentation graphics
have intentional opaque theme backgrounds.

The selected logo is **Interlocking Lanes**, with genuinely alternating
over-under crossings. It accompanies the established slab display type,
cut-corner phase bands and green/orange/blue cues. The README header retains
equal 64px gaps and a right-aligned symbol. No caption is placed inside the logo.
The other three logo concepts remain outside this production package.

**Scope:** iOS and Android phone apps only. No desktop, Watch, Pomodoro,
pre-built workout library, pricing promises or fabricated store download badges.
The timings in artwork are illustrative, not product screenshots.

No GitHub changes, native builds, store submissions or deployment were performed.
