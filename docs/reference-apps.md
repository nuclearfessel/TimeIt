# Reference apps

Written 2026-11-13 from store screenshots, captions, reviews and web searches. Nothing here comes from hands-on use, so test the create and delete flows yourself.

## Shortlist (basic + advanced timers, stacking)

### Seconds (iOS and Android)
- Quick Countdown and Stopwatch modes beside a Circuit Timer.
- Circuit editor: name, number of sets, a list of your own exercises each with a time, "Add Exercise", cut / copy / paste.
- Saved timers live in folders you name ("Sample Timers" is just a folder).
- Full-screen color run screen with an "up next" panel.
- Weak spots: one reviewer could not insert an interval between existing ones; another found timers-within-timers unclear. Free app locks each timer after one run until unlocked (one-time unlock, $7.99 on iOS; Seconds Pro is a separate $7.99 app).
- Orientation: iOS supports portrait and landscape (store listing and AppleVis review). Android: a screenshot shows a landscape run screen; very likely, not confirmed in text.

### Intervals Pro (iOS, standalone Apple Watch)
- "Add New Timer" ladder from simple to advanced: HIIT Timer, Custom Interval Timer, Set Timer (repeating sets of intervals).
- Workout Templates are optional starting points.
- Free tier allows one timer; $2.99/mo, $19.99/yr, $69.99 lifetime.
- Orientation: not confirmed. Test on an iPhone.

### Allez (Android; iOS version not confirmed)
- "Quick routine" screen (Get ready, Warm-up, Work, Rest, Sets, Recovery, Cycles, Cooldown) next to saved Routines built from blocks. "Add block" is marked PRO.
- Bottom tabs: Quick, Templates, Routines, History, Settings. Routines: swipe to edit or delete, hold to duplicate.
- Newer app; pricing and age not verified.
- Orientation: not confirmed; all store screenshots are portrait. Test on an Android phone.

## Why the others were left out
- Workout Timer: HIIT & Gym is strongest at chaining blocks but ships a built-in routine library and rep/tempo features.
- Exercise Timer and Yay!Timer bundle pre-built exercises or routines.
- Timer Plus stacks well, but one reviewer said saved timers can't be edited.
- Bit Timer and Tabata Xtreme are basic only.

## To test hands-on in each app
1. Create a stacked timer (work, rest, repeats, sets), save it, edit it, delete it.
2. Can you insert an interval mid-list?
3. Can you delete the sample or template content?
4. Rotate the phone during a running timer: does the run screen rotate, and does the editor?
5. Lock the screen mid-timer: do cues still play?
